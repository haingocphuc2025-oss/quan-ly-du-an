# DU AN WEB QUAN LY

Day la diem vao duy nhat cua workspace.

## Hai khu vuc lam viec

1. `01_SPEC/` — viet, duyet va quan ly yeu cau.
2. `02_DU_AN_THI_CONG/` — code, test, staging, nghiem thu va phat hanh.

## Luong cong viec

`De xuat -> Cho duyet -> Da duyet -> Thi cong -> Kiem thu -> Nghiem thu -> Baseline`

## Nguon thong tin chinh

- Trang thai spec: `01_SPEC/DANH_MUC_SPEC.md`.
- Quy trinh thi cong: `02_DU_AN_THI_CONG/QUY_TRINH.md`.
- Trang thai phien ban: `02_DU_AN_THI_CONG/TRANG_THAI.md`.
- Mau ban giao: `02_DU_AN_THI_CONG/03_BAN_GIAO/MAU_BAN_GIAO.md`.

## Quy tac bat buoc

- Khong thi cong spec trong `02_CHO_DUYET`.
- Khong lay tai lieu trong `99_LUU_TRU_CU` lam chi dao.
- Khong sua file trong `VERSIONS`; luon tao file moi trong `STAGING`.
- Khong nang baseline khi chua co ket qua nghiem thu dat.
