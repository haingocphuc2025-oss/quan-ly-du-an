# QUAN LY SPEC

## Cau truc

- `01_DA_DUYET/`: spec duoc phep giao thi cong.
- `02_CHO_DUYET/`: de xuat moi, ban nhap, spec dang sua.
- `03_KHONG_SU_DUNG/`: spec bi tu choi, yeu cau viet lai hoac da thay the.
- `DANH_MUC_SPEC.md`: so trang thai duy nhat.

## Vong doi

1. Tao spec trong `02_CHO_DUYET/<ten-tinh-nang>/`.
2. Kiem tra spec co muc tieu, pham vi, tieu chi chap nhan, test case va phu thuoc.
3. Nguoi co tham quyen ghi quyet dinh vao `DANH_MUC_SPEC.md`.
4. Neu duyet, chuyen sang `01_DA_DUYET`; neu tu choi, chuyen sang `03_KHONG_SU_DUNG`.
5. Khong copy spec qua nhieu trang thai.

## Thay doi spec da duyet

- Sua nho khong doi hanh vi: cap nhat spec va ghi lich su thay doi.
- Doi pham vi/hanh vi: tao revision moi trong `02_CHO_DUYET`, duyet lai truoc khi thi cong.
- Khong sua spec de hop thuc hoa code da lam sai.

## Dieu kien duyet

- Muc tieu va ngoai pham vi ro rang.
- Tieu chi chap nhan co the kiem tra.
- Test case gom luong chinh, loi va bien.
- Xac dinh baseline, output version va phu thuoc.
- Khong mau thuan voi spec da duyet khac.
