# AUTO LOOP

`TODO -> SPEC_READY -> DOING -> REVIEW -> VERIFY -> REGRESSION -> RELEASE -> DONE`

Fail: `REVIEW/VERIFY/REGRESSION -> FIX -> DOING`.

Spec thieu: `REVIEW/VERIFY -> SPEC_UPDATE -> SPEC_READY -> DOING`.

Neu `attempt >= 5`: `BLOCKED`.

## Controller

1. Nhan muc tieu.
2. Tim/tao spec NEW.
3. Nghien cuu code va reference, hoan thien spec.
4. Tao task va khoa revision.
5. Thi cong staging, review va verify.
6. Phan loai CODE_GAP, SPEC_GAP hoac BOTH.
7. Sua dung lop, tang attempt va lap lai.
8. PASS thi regression, release va nang baseline.
9. Chuyen spec sang DA_TRIEN_KHAI, task sang DONE.
10. Gui mot bao cao cuoi.

Chi hoi khi khong the suy ra nghiep vu, can quyen moi, co nguy co mat du lieu, hoac cung blocker da lap 5 vong.
