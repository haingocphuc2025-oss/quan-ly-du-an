# Quick Start

1. Copy `Hermes-Cloner` into the project or Hermes skills workspace.
2. Tell Hermes to read Constitution, Router, Skill Registry and Plugin Registry.
3. Send URL, screenshot or Figma reference.
4. Use the command:

```text
Dùng Hermes-Cloner.
Chọn đúng mode.
Khảo sát và viết tài liệu trước.
Chỉ giao coding agent sau khi có spec, plan và tasks.
So sánh cùng viewport, sửa đến khi verify pass.
```

5. Review generated reports before release.
