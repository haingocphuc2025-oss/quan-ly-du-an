# Security Rules

- Không lưu mật khẩu, token, cookie hoặc API key vào repo.
- Không thu thập dữ liệu người dùng ngoài phạm vi được phép.
- Không vượt đăng nhập, paywall, CAPTCHA hoặc cơ chế bảo vệ.
- Không copy mã nguồn kín hoặc tài sản không được phép.
- Kiểm tra secret trước commit.
- Sanitize input và không tin dữ liệu từ client.
