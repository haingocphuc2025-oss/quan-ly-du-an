# Documentation Rules

Khi thay đổi hành vi hoặc kiến trúc, cập nhật:

- `README.md`
- `CHANGELOG.md`
- `DECISIONS.md` nếu có quyết định kiến trúc
- `CLONE_NOTES.md`
- `KNOWN_DIFFERENCES.md`
- Hướng dẫn chạy, test và deploy

Tài liệu phải mô tả trạng thái thực tế, không mô tả điều chưa được triển khai.
