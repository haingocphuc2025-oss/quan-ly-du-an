# Design Rules

- UI phải bám `UI_SPEC.md` và `05_DESIGN_SYSTEM/`.
- Dùng design token thay cho CSS rời rạc.
- So sánh cùng route, viewport, zoom và state.
- Desktop, tablet và mobile phải được kiểm tra.
- Không tự tạo thêm biến thể component ngoài spec.
- Sai lệch phải được ghi vào `COMPARE_REPORT.md`.
