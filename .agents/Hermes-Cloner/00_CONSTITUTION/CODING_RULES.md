# Coding Rules

- Mỗi task chỉ sửa đúng file được phép.
- Reuse first, component first, token first.
- Không hardcode giá trị lặp lại.
- Không thêm dependency nếu chưa cần.
- Không tắt test để che lỗi.
- Luôn xử lý lỗi, loading và empty state.
- Chạy lint, typecheck, test và build trước khi bàn giao.
- Commit nhỏ, rõ nghĩa, có thể rollback.
