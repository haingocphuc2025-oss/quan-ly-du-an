- Yêu cầu chưa rõ → `/clarify`

- Cần chuẩn hóa UI → `/extract-design-system`, `/component-map`
- Cần tài liệu triển khai → `/spec`, `/architecture`, `/plan`, `/tasks`
- Cần code → `/build`
- Cần QA → `/review`, `/compare-ui`, `/verify`
- Có lỗi → `/fix`
- Hoàn tất → `/regression`, `/document`, `/commit`, `/release`
