# Update Existing Project

1. `/context` và kiểm tra Git.
2. Chạy baseline build/test.
3. Xác định component tái sử dụng.
4. Viết spec chỉ cho phần thay đổi.
5. Chia task nhỏ, không phá code cũ.
6. Build từng task.
7. Review, compare UI, verify.
8. Regression toàn bộ chức năng cũ.
9. Commit tách biệt và có rollback note.
