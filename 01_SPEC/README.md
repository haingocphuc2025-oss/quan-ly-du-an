# SPEC

Spec chi co hai trang thai:

- `NEW/`: chua trien khai xong. Bao gom spec moi, dang sua, dang thi cong hoac cho nghiem thu.
- `DA_TRIEN_KHAI/`: da code, test va nghiem thu dat trong mot baseline.

## Quy tac

1. SPEC tao tai `NEW/<ten-tinh-nang>/`.
2. THI CONG chi bat dau khi nguoi dung chon spec NEW de giao.
3. Trong luc thi cong va cho nghiem thu, spec van nam o NEW.
4. Chi sau nghiem thu dat va nang baseline moi chuyen sang DA_TRIEN_KHAI.
5. Khong copy mot spec vao ca hai thu muc.
6. Spec bi huy hoac tu choi chuyen vao `02_SOURCE/99_LUU_TRU_CU/`, khong tao trang thai thu ba.

## Spec hop le

- Co muc tieu va ngoai pham vi.
- Co tieu chi chap nhan kiem tra duoc.
- Co test case luong chinh, loi va bien.
- Ghi baseline/output du kien va phu thuoc.
